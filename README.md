# 🧪 다이어터 연금술사 (Dieter Alchemist)

동물의 숲 같은 **코지 라이프 시뮬 + 연금술 크래프팅** 게임.
채집으로 재료를 모아 물약을 빚고, 마시면 캐릭터가 날씬해진다.

> 순수 HTML/CSS/JS 라 **빌드 도구가 없다.** 진행은 `localStorage` 에 저장되고,
> 서버는 기기를 바꿨을 때 되찾기 위한 **사본**이다 (없어도 게임은 그대로 돌아간다).

## ▶ 실행

게임만 볼 거라면 `index.html` 을 브라우저로 열면 바로 플레이된다. (빌드·서버 불필요)

세이브 서버까지 같이 띄우려면:

```bash
npm install
npm start          # http://localhost:8080
npm test           # 생성 데이터 대조 + 번역 누락 + 인물·대사 표 + 수치 약속 + 서버 API
```

브라우저를 띄워 실제로 눌러 보는 검사가 여럿 더 있다 (튜토리얼·밭·복구 코드·
시계를 옮겨 놓는 검사 등). 목록은 `CLAUDE.md` 의 「검사」 절에 있다.

## ☁️ 배포 (Railway)

| 항목 | 값 |
|---|---|
| Root Directory | 비움 (`/`) — **이 저장소의 루트가 곧 게임 폴더다** |
| Start Command | `npm start` |
| 포트 | 기본 8080 |
| 변수 | `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` |

자세한 절차와 함정은 [`server/README.md`](server/README.md).
배포 후 `/api/health` 의 `store` 가 `memory(휘발성)` 면 **재배포마다 세이브가 날아간다.**

## 🎮 코어 루프

1. **🌿 탐험** — 필드(채집지 51곳) · 마을(사람을 만난다) · 밭(심고 거두고 지킨다) 세 갈래.
   크리처 한 마리를 데려가면 속성·날씨·시간대가 맞는 만큼 재료를 더 준다
2. **⚗️ 공방** — 가마솥(2~12구)에 재료를 담아 조합한다.
   **비법서에 있는 장만 만들 수 있고**, 장은 퀘스트와 단계 지급 두 길로 들어온다.
   ⚠️ **「실패작」이 없다** — 흐린 장을 맞혀 보다 틀려도 재료가 한 톨도 안 없어진다
3. **✨ 마이 룸** — 물약을 마셔 비주얼·아우라를 올리고, 옷을 갈아입고, 크리처를 전시한다.
   운동·포만감·스태미나도 여기에 있다
4. **🏆 랭킹** — 여신 단계(매력 100)부터 주간 리그가 열린다

레시피 **136**(물약 106 · 크리처 30) · 재료 **111** · 채집지 **51** · 가마솥 **11** ·
커스터마이징 **150벌**. 데이터는 손으로 안 늘리고 **축 표에서 생성한다**(`tools/gen*.js`).

## 📖 이야기

1막부터 에필로그까지 **다섯 막**이 이어진다 — 퀘스트 **16** · 컷씬 **41** ·
마을 **여덟** · NPC **일곱** · 키워드 **열넷**.

- **마을은 점수가 아니라 키워드로 열린다.** 한 사람에게 들은 말을 다른 사람에게
  가져가는 것이 곧 조작이고, 그것이 이 게임의 주제(「잇는다」)다
- **호감도는 물약을 만들어 준 것에서만 오른다** — 매력·비주얼은 한 톨도 안 섞인다

## ⚡ 에너지 (행동력)

- 로컬 자정마다 **상한까지** 충전된다. 상한은 매력 **단계**로 오른다
  (새싹 1000 → 여신 1800 · 단계마다 +200)
- **채집 AP 는 지대마다 다르다** — 포근 평야 6 → 황량 황무지 17.
  조합은 25 이고, **성공하면 현자의 결정이 들어온다**

## 📊 등급

매력 총합(비주얼 + 아우라 + 크리처 보너스)에 따라:

🌱 새싹 0 → 🌸 꽃봉오리 15 → 🧚 요정 35 → 👑 뮤즈 60 → ✨ 여신 100

> **해금은 「여태 닿은 최고 매력」으로 판정한다**(`charmPeak()`).
> 한 번 연 것은 무슨 이유로도 안 닫힌다.

## 📁 파일

| 파일 | 역할 |
|------|------|
| `index.html` | 게임 셸 (스플래시·인트로는 인라인 — 의도된 중복) |

| `game.js` | 상태 관리 / 로직 / 렌더링 (`localStorage` 저장) |
| `sync.js` | 서버 저장 동기화 (오프라인 우선, `window.Sync`) |
| `avatar.js` | SVG 페이퍼돌 아바타 + 마이 룸 배경 (`window.Avatar`) |
| `intro.js` · `tutorial.js` | 인트로와 튜토리얼 열여덟 단계 |
| `portrait.js` · `creature.js` · `village.js` | 인물 초상화 · 크리처 SVG · 마을 지도 |
| `i18n.js` | 한국어·영어 문구 (`window.I18N`) |
| `sfx.js` | WebAudio 기반 효과음 (에셋 불필요) |
| `a11y.js` | 대비·레이아웃·잠금 표현 검증기 (`checkUI()`) |
| `style.css` | 코지 파스텔 스타일 |
| `tools/` | 생성기와 검사기 (`npm test` 가 부른다) |
| `server/` | 세이브 서버 + 게임 호스팅 — [배포 안내](server/README.md) |

> 모듈 시스템이 없다. `<script>` 순서가 곧 의존성 순서이고
> **전역 이름이 파일끼리 겹치면 그 파일이 통째로 안 돈다** (`npm run test:globals`).

## 💾 저장

게임을 **초기화하기 전까지 모든 진행이 남는다.**

| 어디에 | 무엇이 |
|---|---|
| 브라우저 (`localStorage`) | **항상 여기가 진짜다.** 서버가 없어도, 오프라인이어도 그대로 플레이된다 |
| 서버 (Railway) | 사본. 브라우저 데이터를 지우거나 기기를 바꿔도 이어서 할 수 있다 |

- 저장할 때마다 `rev` 가 오르고, 더 큰 `rev` 를 가진 쪽이 최신이다
- 설정 화면의 **복구 코드**를 다른 기기에 입력하면 그 진행을 이어서 한다
  (먼저 받아 보고 **누구의 세이브인지 보여 준 다음에야** 갈아탄다)
- **게임 초기화**를 하면 로컬과 서버 사본이 함께 지워진다
- 상단 시계 옆의 ☁️ 를 누르면 지금 저장 상태를 알려 준다
- ⚠️ **밭만은 서버가 정본이다** — 남이 내 밭에서 가져간 결과가 적히는 곳이라,
  세이브 안에 두면 내가 다음에 저장하는 순간 없던 일이 된다

플레이 기록은 마이 룸의 **📔 플레이 기록**에서 볼 수 있다.

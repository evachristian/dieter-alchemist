# 🧪 다이어터 연금술사 (Dieter Alchemist)

동물의 숲 같은 **코지 라이프 시뮬 + 연금술 크래프팅** 게임.
재료를 채집하고, 연금술로 **물약**과 **크리처**를 제조해서
내 캐릭터의 **비주얼·아우라를 과시**하는 것이 목표입니다.

> 기존 저장소(DragON POKER)와 분리된 **독립 저장소의 신규 게임**입니다.
> 순수 HTML/CSS/JS 라 빌드 도구가 없고, 진행 상황은 `localStorage`에 저장됩니다.

## ▶ 실행

게임만 볼 거라면 `index.html` 을 브라우저로 열면 바로 플레이됩니다. (빌드·서버 불필요)

세이브 서버까지 같이 띄우려면:

```bash
npm install
npm start          # http://localhost:8080
npm test           # 서버 API 검사
```

## ☁️ 배포 (Railway)

| 항목 | 값 |
|---|---|
| Root Directory | 비움 (`/`) — **이 저장소의 루트가 곧 게임 폴더다** |
| Start Command | `npm start` |
| 포트 | 기본 8080 |
| 변수 | `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` |

자세한 절차와 함정은 [`server/README.md`](server/README.md).

## ⚡ 에너지 (행동력)
- 현실 24시간 = 게임 24시간. **로컬 자정(00:00)마다 하루치 1000 충전** (현재 상한 1000)
- **채집(⚡10)**·**연성(⚡25)** 시 소모 (값은 `data.js`의 `ENERGY.cost`에서 조정)
- 상단 에너지 바에 현재량 / 상한 / 다음 충전까지 카운트다운 표시, 앱을 열어둔 채 자정이 지나면 자동 충전
- 추후 크리처·공간 돌보기도 동일한 `spendEnergy()`로 소모 예정. 유료 구매 시 상한 확장 여지(`cap` 분리)

## 🎮 코어 루프 (현재 MVP)
1. **🌿 채집** — 꽃 들판 / 이끼 숲 / 수정 동굴에서 재료를 가중 랜덤으로 획득 (⚡ 소모)
2. **⚗️ 공방** — 가마솥에 재료 2~3개를 넣고 조합 → 새 레시피 발견 (⚡ 소모)
   - 유효 조합 → **물약**(스탯 상승용) 또는 **크리처**(전시용) 제조
   - 무효 조합 → 실패작(재료 소모)
3. **✨ 마이 룸** — 물약을 마셔 비주얼/아우라 영구 상승, 크리처 전시(패시브 매력), **매력 총합 과시**
   - 👗 **내 아바타 + 옷장** — 5개 바디 파츠(머리·몸통·팔·허벅지·종아리)로 조립되는 SVG 아바타 커스터마이징
     - 커스터마이징(잠금/해금): **헤어**(스타일) · **헤어컬러**(기본 5종 + 해금) · **표정** · **문신**(초기 미보유, 플레이로 획득)
     - 옷: 상의·하의 따로 입기 **또는** 원피스(상하 일체)
     - 악세사리: 서클렛 · 귀걸이 · 목걸이 (추후 확장 가능)
     - `starter`가 아닌 항목은 🔒 잠금 → `unlockCosmetic(id)`로 해금 (진행 보상에 연결 예정)

## 💾 저장
게임을 **초기화하기 전까지 모든 진행이 남는다.**

| 어디에 | 무엇이 |
|---|---|
| 브라우저 (`localStorage`) | 항상. 서버가 없어도, 오프라인이어도 그대로 플레이된다 |
| 서버 (Railway) | 사본. 브라우저 데이터를 지우거나 기기를 바꿔도 이어서 할 수 있다 |

- 저장할 때마다 `rev` 가 오르고, 더 큰 `rev` 를 가진 쪽이 최신이다.
- 설정 화면의 **복구 코드**를 다른 기기에 입력하면 그 진행을 이어서 한다.
- **게임 초기화**를 하면 로컬과 서버 사본이 함께 지워지고 처음부터 시작한다.
- 상단 시계 옆의 ☁️ 를 누르면 지금 저장 상태를 알려 준다.

플레이 기록(채집·조합·발견·플레이 시간 등)은 마이 룸의 **📔 플레이 기록**에서 볼 수 있다.
